# Evoxia

Interactive explainer site for Evoxia Labs India (solar-grade polysilicon). Single static page, no build step.

## Host on GitHub Pages
1. Create a new repository and upload `index.html`, `.nojekyll` and `README.md` to the root.
2. Go to Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<username>.github.io/<repo>/`.

Source: Evoxia pitch deck (confidential). Figures are company claims, not verified.
